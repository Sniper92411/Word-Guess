欢迎游玩猜词游戏！\
这是一个英语单词猜测推理小游戏，你可以通过询问单词中包含的字母，结合常见的字母排列，最终揭露真相。

基本玩法：游戏开始时：程序会隐藏一个单词，其中所有字母都是未知的。程序也会告诉你这个单词的长度。
游戏玩法：你可以询问，单词中是否包含某个字母。如果单词中至少有一个你询问的字母(无论大小写)，即猜测字母成功，则程序会将这些字母所在的位置的字符显现出来。\
例如：在询问了一个长度为6的单词 ______ 中是否有字母e后，程序确认有一个对应的字母，并展示了E或e在单词中的位置：\___e\__\
反之，猜测字母失败，则你将失去1点生命值。\
每局游戏玩家有10点生命值。当生命值小于等于0时，游戏失败。\
如果玩家成功揭露出整个单词，则游戏胜利。

整个单词的猜测(称为 猜词)：\
如果你在进行了若干次猜测后，已经非常确定正确的单词了，则你可以直接输入整个单词，进行猜词。\
若你猜的单词与正确的单词相符，则游戏直接胜利。否则，你将失去2点生命值。

提示：
每局游戏中，玩家可以在任何时候获取提示。\
提示的效果是展示这个单词的中文释义。\
提示的使用方法：输入字符 0。\

结束：
玩家可以输入单个字符 / 来主动放弃游戏。\
当达成胜利或失败的条件时，程序会自动结束游戏，并展示正确的单词、它的中文释义和玩家在本局内的表现（包括剩余生命值、猜出的字母个数等）\
然后，游戏会根据本局表现，展示评级。

祝你玩得开心！
